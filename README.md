### 😷 Face Mask Detection

**Transfer Learning • Fine-Tuning • Computer Vision**

A high-performance Computer Vision system built using **Transfer Learning** and **Fine-Tuning** on top of the lightweight **MobileNetV2** architecture to detect whether individuals are wearing face masks.

**Technical Highlights**

* 🧠 MobileNetV2 pretrained on ImageNet
* 🔧 Transfer Learning for efficient feature extraction
* 🎯 Fine-Tuning of selected top layers
* 🖼️ Image augmentation for better generalization
* 👁️ OpenCV integration
* 📈 Precision, Recall & F1 evaluation

**Tech Stack**

`Python` `TensorFlow/Keras` `MobileNetV2` `OpenCV` `Transfer Learning` `Deep Learning`
