### Featured Projects

#### AI & Machine Learning

##### Face Mask Detection (Transfer Learning & Fine-Tuning)
A high-performance Computer Vision system built using **Transfer Learning** and **Fine-Tuning** on top of the lightweight **MobileNetV2** architecture to detect whether individuals are wearing face masks correctly in real-time.

* **Key Features & Technical Highlights:**
  * **Transfer Learning Core:** Utilized **MobileNetV2** pre-trained on ImageNet as a feature extractor for fast convergence and high feature generalization.
  * **Fine-Tuning Strategy:** Unfrozen selected top layers of MobileNetV2 alongside custom Dense/Dropout classification layers to adapt specifically to facial feature nuances and mask boundaries.
  * **Dataset & Augmentation:** Trained on a diverse image dataset of masked and unmasked faces using data augmentation techniques (rotation, scaling, flipping) to prevent overfitting and improve real-world generalization.
* **Tech Stack:** `Python` | `TensorFlow/Keras` | `MobileNetV2` | `OpenCV` | `Transfer Learning` | `Deep Learning`
